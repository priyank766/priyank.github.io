    NowSaarthiOS, since June 2026

    I’m an AI engineer at SaarthiOS. I built Right Hand, an AI chief of staff. It reads an executive’s mail and documents and works out what actually needs their attention. It’s three agents on the Anthropic SDK and AWS Bedrock:

    • The Profiler learns how each executive works from their past mail.
    • The Interpreter groups related emails into one situation.
    • The Chief of Staff narrows 100+ open situations to the five that need action today, and recommends the next step in the executive’s usual tone.

    It replaced an earlier rule-based context graph, which stopped scaling at the second client. Right Hand is live with three clients now, and the people using it are promoters, CFOs and CEOs. I work with them directly.

    Anchor

    May 2026 · TypeScript, MCP, SQLite
    anchormem.me · code

    Why does every coding agent start cold when I switch tools?

    Anchor is a local-first MCP server that gives Claude Code, Cursor, Codex and the rest one shared memory per project, kept in a SQLite file on your own machine. A new session gets a short, token-budgeted gist instead of the old transcript.

    Across eight scenarios it replaced 98,200 tokens of transcript with 2,239, a 44× cut, and recovered every critical fact. Recall stays under 4 ms at 10,000 memories.

    The catch: precision is 82.9%, so roughly one memory in six that it pulls back wasn’t needed.

    RLM

    May 2026 · Python, Ollama, QLoRA
    write-up · code

    Does the Recursive Language Models result hold up on a 6 GB laptop GPU?

    I reproduced Zhang, Kraska and Khattab’s paper with a 2B Qwen model on an RTX 4050. The document never goes into the context window. It sits in a Python REPL as a variable, and the model writes code to read slices of it and calls itself on the pieces.

    At 64K tokens the recursive setup found the needle 67% of the time. The same model reading the document directly found it 33% of the time.

    The catch: at 16K the plain model won, 100% to 67%, because the 2B model’s code got sloppy. A recursive answer also takes about 60 seconds, against 15.

    Hermes-BIO

    April 2026 · Python, Gemini
    code

    Can an agent do a week of drug-target triage in minutes, without being handed the answers?

    You give it a disease name. It picks a target, looks for druggable proteins nobody has tried hard on, and finds approved drugs that bind the target but are approved for something else. It chains UniProt, OpenTargets, RCSB PDB, AlphaFold DB and ChEMBL through a function-calling loop.

    On six benchmark diseases it recovered the textbook target every time, in about 38 seconds each, with no seeded knowledge. For rheumatoid arthritis and Parkinson’s it picked the newer targets, TYK2 and LRRK2.

    The catch: it’s a triage layer between a researcher and the literature. It doesn’t replace the lab.
